## Comments

**2026-10-07, done.**
- **README** rewritten for a newcomer: what the crate is, its status and pinned commit, a Rust example (run as a doc test, so it can't drift), the CLI, `scripts/check.sh`, the Bun-side commands, the layout, and the license.
- **CONFORMANCE.md**: the contract, what's checked and how, fuzzing history (320,000 inputs), what conformance testing found in the core and in the reference (quirks 1–10), and a table of divergences. Its counts (300 parse cases, 245,513 results compared, 74,313 stage prefixes, 44 prompts, 1,417 merges, 325 serializations, 187 enrich cases, 10 quirks) are generated by `tests/report.rs`, which fails if they go stale; `UPDATE_REPORT=1` rewrites them.
- **Crate docs:** a front page with a runnable example for each part (parsing, errors, streaming, prompts, edit mode, back to source) and the limits. Every public item is documented, and `#![warn(missing_docs)]` keeps it that way (clippy runs with `-D warnings`). Four public types that couldn't be named from outside the crate are now re-exported: `QueryStatement`, `MutationStatement`, `JsObject`, `RefType`. `scripts/check.sh` also builds the docs with warnings as errors.
- **Benchmarks:** a full re-run was attempted, but the machine was busy (a virtual machine and kernel_task using most of a core), so both sides came out 4–7× slower, unevenly, and the run was discarded. The published table stays as measured on an idle machine on 2026-10-06; the reference hasn't changed, and the core's synthetic-program times were re-confirmed on an idle machine after ticket 14. BENCHMARKS.md says so. Re-run `scripts/bench.sh` on an idle machine to refresh it.
- **Newcomer check:** the files git would commit, copied to a fresh directory, with Bun removed from `PATH` and a fresh target directory: `scripts/check.sh` passes (13 test binaries and 7 doc examples).

Under the same load: 1.2× on eight runs out of eight. A planted quadratic parser (re-parse everything per push) measures 4.1× and fails it.
