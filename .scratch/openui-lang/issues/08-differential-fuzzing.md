
**2026-10-06, done.**
- `reference/serve.ts`: a long-lived Bun process taking JSON-line requests (`lib`, `input`, `root`, push `sizes`) and answering with fingerprints of the one-shot result, the tokens and every push step, or `threw`.
- `crates/openui-lang/examples/fuzz/` (`scripts/fuzz.sh [--seed N] [--count N] [--only K] [--no-save]`). Half the programs are generated from a library's grammar: components with 0 to params+2 args, nasty string escapes and lone-surrogate escapes, odd numbers, AST-kind object keys, refs, state, operators, builtins, Query/Mutation, comments, prose and fences. The other half are corpus cases mangled 1–3 ways (truncate, delete, insert noise, duplicate or swap lines, wrap in prose or fences, CRLF). Each program also gets a random push chunking. Program K of seed S replays alone with `--only K`.
- Shrinking: whole lines, then halving runs of chars, keeping the same outcome. One-shot mismatches shrink one-shot; streaming ones shrink under one-char pushes so any chunking reproduces them. Mismatches are saved to `conformance/fuzz.json` (source `fuzz`, origin `seed S, program K`), and `scripts/fuzz.sh` regenerates goldens so `cargo test` covers them without Bun. The test loader and the runner now read `fuzz.json`.
- **Found and fixed one core bug:** choosing the entry statement must compare with `Query`/`Mutation` by name, not `is_reserved_call` (`s=)\nr=@toString(`, shrunk from 208 chars; saved as `fuzz/3cdbf706`). Quirk 2 now notes the reference's own inconsistency there.
- **Explained, not saved:** an object or null assigned to `__proto__` replaces the prototype in the reference (documented in ticket 06). The generator only assigns plain values there; mutations can still produce the object case, and a minimal mismatch containing `__proto__` is reported as explained.
