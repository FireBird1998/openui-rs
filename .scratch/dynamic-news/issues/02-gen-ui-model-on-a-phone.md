# 02 — Can a gen-UI model run on an Android phone?

Type: research
Status: open
Blocked by: none

## Question

Can a model that writes OpenUI Lang, such as Thesys's open-weights OUI-1, run on a recent Android phone fast enough to stream a story screen? Find out:
- the model's size and quantized variants
- the runtimes available on Android
- tokens per second on mid-range and flagship phones
- battery and heat cost
